研播 Live Lab

浏览器原生 WebRTC · 一对多直播教学

写给想搞懂直播链路的开发者

一个人开播，
多个人在同一个房间里看。

全程使用浏览器自带的 RTCPeerConnection、getUserMedia， 不用包装库把 SDP 和 ICE 藏起来。主播为每位观众单独建一条连接， 信令过程会实时写在房间右侧的学习面板里。

或加入已有房间
1

开房间

信令服务器只分配一个短房间号，并记住谁是主播。音视频不经过服务器。

2

采集并开播

主播调用 getUserMedia 拿到本地流。有观众时，为每个人 createOffer。

3

握手后直连

观众回 Answer，双方交换 ICE 候选。连通后媒体走 P2P，学习面板会标出状态。

仅用于本地学习。生产级直播通常会改用 SFU，原因写在 README 里。
